## W06-G4 상세 — GELU vs ReLU 수치 근거

| x | GELU(x) | ReLU(x) |
|---|---|---|
| −3.0 | −0.003637 | 0.000000 |
| −2.0 | −0.045402 | 0.000000 |
| −1.0 | **−0.158808** | 0.000000 |
| −0.5 | −0.154286 | 0.000000 |
| 0.0 | 0.000000 | 0.000000 |
| +0.5 | +0.345714 | +0.500000 |
| +1.0 | +0.841192 | +1.000000 |
| +3.0 | **+2.996363** | +3.000000 |

원점 부근 수치미분 (h=1e-4):

| x | GELU 미분 | ReLU 미분 |
|---|---|---|
| −0.01 | 0.4920 | 0.0000 |
| 0.00 | 0.5000 | 0.5000 |
| +0.01 | 0.5080 | **1.0000** |

→ ReLU 는 0 에서 미분이 0→1 로 급변(꺾임), GELU 는 연속적으로 변한다.
→ 큰 양수에서 y=x 수렴: x=3 에서 차이 0.003637.
