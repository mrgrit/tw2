## 특기 사항 — 무작위 가중치 생성 문자열의 재현성

교재 정답지 `"Hello, I am Featureiman Byeswickattribute argue"` 가
**aarch64 / GB10 / torch 2.9.1+cu130 / CPU 실행** 환경에서 문자 단위로 재현되었다.

```
생성 후 토큰 ID: [15496, 11, 314, 716, 27018, 24086, 47843, 30961, 42348, 7267]
디코딩 결과   : 'Hello, I am Featureiman Byeswickattribute argue'
```

이는 `torch.manual_seed(123)` → 모델 생성 → `eval()` 순서가 지켜지면 CPU 상에서
초기 가중치가 플랫폼·버전에 무관하게 결정적으로 생성됨을 뜻한다. 교재 7.11 트러블슈팅의
"시드 호출 위치(모델 생성 전이어야 함)" 진단이 정확하다.

P7-4의 상위 1위 토큰이 `' Feature'`(ID 27018)로, P7-3 생성 결과의 5번째 토큰과
일치한다 — 두 미션의 내적 일관성도 확인된다.
