| | 예측 spam | 예측 ham |
|---|---|---|
| **실제 spam** | TP 141 | FN 10 |
| **실제 ham** | FP 3 | TN 146 |

오분류 3건 — "사람이 봐도 헷갈릴 만한가":

1. `thesmszone.com lets you send free anonymous and masked messages..im sending this message from there..do you see the potential for abuse???`
   → **헷갈릴 만하다.** 스팸 사이트를 홍보하는 문장과 그 사이트의 위험성을 지적하는 문장이
   같은 단어(`free`, `.com`)를 쓴다. 사람도 마지막 `do you see the potential for abuse???`
   를 읽어야 정상임을 안다. 모델은 앞부분의 스팸 어휘에 끌렸다.
2. `Hello. We need some posh birds and chaps to user trial prods for champneys. Can i put you down? I need your address and dob asap. Ta r`
   → **헷갈릴 만하다.** 실제로는 스팸인데 개인적 말투(`Ta r`, `Can i put you down?`)를 쓴다.
   주소와 생년월일을 요구하는 것이 스팸의 핵심 신호인데, 어휘 수준에서는 정상 문자와 구별되지 않는다.
3. `Filthy stories and GIRLS waiting for your`
   → **헷갈리지 않는다. 모델이 명백히 틀렸다.** 다만 원문이 잘려 있어(`for your` 에서 끝남)
   문장이 완결되지 않았다. 데이터 자체의 결함에 가깝다.

가장 위험한 지점은 확신도다. 영어 스팸풍(0.6459)보다 한국어 정상문(0.7753)에
**더 높은 스팸 확률**을 준다. softmax 는 반드시 둘 중 하나에 확률을 몰아주므로
"모르겠다"고 답할 방법이 이 구조에는 없다. **"돌아간다"와 "믿을 수 있다"는 다르다.**

## 결함 #12 — P11-3 훈련 가능 파라미터 정답지가 틀렸다 (**중대**, 교재-수치오류)

**위치**: Week11-13 교재 11.5절 P11-3 예상 결과

**교재 서술**:
> 훈련 가능 파라미터 = 블록 **7,085,568** + 최종 LN 1,536 + 새 헤드 (768×2+2)=1,538
> → **7,088,642개** (전체의 약 **4.3%**)

**실측 — 두 군데가 틀렸다**:

```
qkv_bias=False → 블록 파라미터 7,085,568   ← 교재가 쓴 값 (7주차 설정)
qkv_bias=True  → 블록 파라미터 7,087,872   ← P11-3 이 요구한 설정
차이 = 3 x 768 = 2304 (Q,K,V 각각의 bias)

P11-3 이 요구한 설정 기준 합계: 7,087,872 + 1,536 + 1,538 = 7,090,946
교재 정답지                    : 7,085,568 + 1,536 + 1,538 = 7,088,642

수술 전 전체(50257 헤드): 163,037,184 → 비율 4.35%  ← 교재의 "약 4.3%" 는 이 값
수술 후 전체(2 헤드)    : 124,441,346 → 비율 5.70%  ← 실제
```

**(a) 블록 값이 qkv_bias=False 기준이다.**
P11-3 1번은 `(ctx 1024, qkv_bias=True)` 로 로드하라고 명시한다. 그런데 정답지의
블록 값 7,085,568 은 **7주차 GPT_CONFIG_124M(qkv_bias=False)** 의 값이다.
교재 스스로 "7주차 분해표의 블록·LN 값이 그대로 재등장한다"고 안내하는데,
바로 그 지시가 오류의 원인이다 — 10주차에서 qkv_bias 를 True 로 바꿨다는 사실이
11주차 산식에 반영되지 않았다. QKV 각각의 bias 768개씩, 총 2,304개가 누락됐다.

**(b) "전체의 약 4.3%" 는 수술 전 모델 기준이다.**
헤드를 Linear(768, 50257) → Linear(768, 2) 로 갈아 끼우면 전체 파라미터가
163,037,184 → **124,441,346** 으로 3,860만 개 줄어든다. 4.3% 는 사라진 헤드를
포함한 분모로 계산한 값이다. 개조 후 모델 기준으로는 **5.70%** 다.

**학생에게 미치는 영향**: P11-3 검증 항목이 "산식으로 분해해 표시하라"이고
11.10 검증 노트 가이드가 "7,088,642의 손계산을 남겼는가"를 채점 포인트로 삼는다.
정직하게 계산한 학생은 7,090,946 을 얻고 **자기가 틀렸다고 판단해 되돌아간다.**
가장 흔한 '수정' 은 qkv_bias 를 False 로 바꾸는 것인데, 그러면 10주차 가중치 이식이
깨진다(V10-3 1번이 잡는 그 오류다).

**권고 (교재 수정안)** — 예상 결과를 아래로 교체.

```text
**예상 결과 (정답지):** 2번 — 모델은 yes/no로 답하지 못하고 텍스트를 이어 쓴다.
훈련 가능 파라미터 = 블록 7,087,872 + 최종 LN 1,536 + 새 헤드 (768×2+2)=1,538
→ **7,090,946개**.
⚠️ 7주차 분해표의 블록 값은 7,085,568 이었다. 여기서 2,304 (= 3 × 768) 이 늘어난
   이유를 반드시 짚을 것 — 10주차에서 **qkv_bias=True** 로 바꿨기 때문에
   Q·K·V 각각에 bias 768개가 붙었다. 이 차이를 설명하지 못하면 이식 설정을
   이해하지 못한 것이다.
비율은 분모를 조심하라. 헤드를 Linear(768,50257) → Linear(768,2) 로 갈아 끼우면
전체가 163,037,184 → **124,441,346** 으로 줄어든다. 따라서 7,090,946 / 124,441,346
= **5.70%** 다. (수술 전 분모로 계산하면 4.35% 가 나오는데, 그 모델은 이미 없다.)
```

## 결함 #13 — P11-6 의 "355M ≥ 124M" 이 성립하지 않는다 (**중간**, 교재-수치오류)

**위치**: Week11-13 교재 11.8절 P11-6 예상 결과

**교재 서술**:
> 대체로 (a) < (b) ≤ (c), 그리고 **355M ≥ 124M**

**실측 — 3개 전략 중 1개에서만 성립**:

| 전략 | 124M | 355M | 355M ≥ 124M ? |
|---|---|---|---|
| (a) 새 헤드만 | 84.00% | 82.67% | ❌ −1.33%p |
| (b) 교재 | **96.33%** | 85.00% | ❌ **−11.33%p** |
| (c) 전층 | 95.33% | 97.67% | ✅ +2.34%p |

`(b) ≤ (c)` 도 124M 에서는 성립하지 않는다 (96.33% > 95.33%).

**원인 규명 — 미수렴이 아니다.** 5에폭 시점의 355M/(b) train 정확도가 82.5% 로
낮아 "에폭이 부족해서"라는 가설을 세우고 **에폭을 4배(20)로 늘려 재측정**했다.

```
124M / (b) 5에폭  : test 96.33%
355M / (b) 5에폭  : test 85.00%
355M / (b) 20에폭 : test 94.33%   ← 4배를 돌려도 못 넘는다
```

20에폭에서도 124M/(b) 에 2%p 못 미친다. **전략 (b) 자체가 355M 에 불리하다.**

**진짜 원인은 "마지막 블록 1개"라는 고정 규칙이다.**
(b) 는 층 수와 무관하게 마지막 블록 **1개**만 푼다. 124M 은 12층이므로 1/12(8.3%)를
푸는 것이고, 355M 은 24층이므로 1/24(4.2%)만 푸는 셈이다. 실제로 훈련 가능 비율이
124M 5.70% vs 355M **3.55%** 로 355M 쪽이 더 낮다. 모델을 키웠는데 **적응 여력은
오히려 줄었다.** 그래서 355M/(b) 는 124M/(b) 를 못 이긴다.
반면 (c) 전층에서는 모델 크기의 이점이 그대로 나타나 97.67% 로 최고를 찍는다.

이것은 교육적으로 매우 좋은 관찰인데, 교재의 예상 결과가 정반대를 말해
학생이 자기 실험을 의심하게 만든다.

**권고 (교재 수정안)** — 예상 결과를 아래로 교체.

```text
**예상 결과:** 동결 축에서는 대체로 (a) < (b) 다. 모델 축은 **전략에 따라 갈린다** —
(c) 전층에서는 355M 이 124M 을 앞서지만, (a)·(b) 에서는 **124M 이 더 나을 수 있다.**
이유를 표에서 직접 찾아보라. 힌트: (b) 는 층 수와 무관하게 "마지막 블록 1개"만
푸는 규칙이다. 12층 모델에서는 1/12 를, 24층 모델에서는 1/24 만 푸는 셈이다.
훈련 가능 파라미터 **비율** 열을 두 모델에서 비교해 보라.
(참고 실측: 124M/(b) 5.70% → 96.33%, 355M/(b) 3.55% → 85.00%.
 355M/(b) 를 20에폭으로 늘려도 94.33% 로 124M/(b) 를 넘지 못한다 — 미수렴이 아니라
 전략의 문제다.)
헤드만 훈련(a)도 파라미터 1,538개로 84% 를 낸다 — 사전 훈련 표현이 이미
얼마나 좋은지의 방증이다. **정답은 표가 말하게 하라.**
```

11.12 트러블슈팅에 한 행 추가:
```
| 355M 이 124M 보다 나쁘게 나옴 | 전략 (b) 는 층 수와 무관하게 블록 1개만 푼다 — 깊은 모델일수록 푸는 비율이 작아진다 | 정상이다. 훈련 가능 '비율' 열을 비교하고, (c) 와 대조할 것 |
```
