
**출제 권고**: 버그 #8 은 **블록 1개만 주면 기울기 차이가 0.5배에 그쳐** 학생이

손실 게이트 단독 판정은 취약하다 — 기울기 비율을 주 근거로 삼게 유도해야 한다.

### #10 상세 — 교재 표현이 모호하다 (출제 시 주의)

교재 8.7절: "argmax를 마지막 위치가 아닌 전체에 적용"

이 문구를 그대로 구현하면 **버그가 되지 않는 경우가 있다**:

```python
# 이것은 버그가 아니다 — 정답과 수학적으로 동일하다
idx_next = torch.argmax(logits, dim=-1)[:, -1:]     # → [[38621]]
idx_next = torch.argmax(logits[:, -1, :], dim=-1, keepdim=True)  # → [[38621]]
# 동일: True
```

`argmax(dim=-1)` 은 **위치별** argmax 를 내므로, 그중 마지막을 취하면 결국
마지막 위치의 argmax 와 같다. 진짜 버그가 되는 구현은 두 가지다:

| 구현 | 결과 | 증상 |
|---|---|---|
| `argmax(logits.flatten(1), dim=-1)` | 토큰 ID **233626** | 어휘 50257 초과 → IndexError |
| `argmax(logits, dim=1)` | shape `(1, 50257)` | 토큰 하나가 아니라 위치 인덱스 벡터 |

**출제 권고**: 버그 은행 #10 의 서술을 구체화한다 —
`"argmax 를 위치 축까지 평탄화해 적용 (logits.flatten(1))"`.
그러지 않으면 조교가 "버그"를 심었는데 실제로는 정상 동작하는 파일을 배포할 수 있다.

## 결함 #9 — 버그 은행 #8·#10 의 서술이 출제에 부족하다 (경미, 교재-프롬프트결함)

두 항목이 "그대로 구현하면 의도한 결과가 안 나오는" 문제를 갖는다.

| # | 현재 서술 | 문제 | 권고 서술 |
|---|---|---|---|
| 8 | 잔차 덧셈 누락 (`x = Dropout(FF(LN(x)))`) | 블록 1개에 심으면 기울기 차이가 0.5배로 약해 판정이 모호 | 잔차 덧셈 누락 — **12층 GPT 전체에 심을 것**(1개 블록은 검출력 부족) |
| 10 | argmax를 마지막 위치가 아닌 전체에 적용 | `argmax(dim=-1)[:, -1:]` 은 정답과 동일해 버그가 아님 | argmax 를 **위치 축까지 평탄화**해 적용 (`logits.flatten(1)`) — 어휘 범위를 넘는 ID 가 나온다 |

또한 8.7절 난이도 분류에서 #8을 "중간(4~6, 8~9)"으로, #10을 "어려움(7, 10)"으로
두었는데, 실측 기준으로는:
- #10 은 **즉시 IndexError** 가 나므로 오히려 쉬운 편이다 (어휘 범위 초과가 명백한 단서)
- #7 (transpose 누락)이 진짜 최고 난도다 — **shape 이 맞고 오류도 안 나며 값만 오염**된다.
  이 판정은 교재 서술("shape는 맞는데 값이 틀린 최고 난도")과 일치한다 ✓

**권고**: #10 을 "중간"으로 이동, #8 은 "12층에 심을 것" 조건을 명기.
