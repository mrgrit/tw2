# 발견된 결함

## 결함 #6 — P3-5 예시 문장에 중복 토큰이 없다 (**중대**, 교재-프롬프트결함)

**위치**: Week3-5 교재 3.7절 P3-5 1번 항목

**교재 서술**:
> 1. 같은 토큰이 두 번 나오는 짧은 시퀀스를 만들 것
>    (예: **"the cat and the dog"** 를 gpt2로 인코딩 — **'the'가 두 번**)

**실측 — 'the' 는 두 번 나오지 않는다**:
```
'the cat and the dog'
   ids : [1169, 3797, 290, 262, 3290]
   조각: ['the', ' cat', ' and', ' the', ' dog']
   중복 토큰: 없음   ← 실험 불가
```

**원인**: GPT-2 BPE 는 **선행 공백을 토큰에 붙여** 다룬다. 따라서
- 문장 맨 앞의 `the` → ID **1169** (공백 없음)
- 문장 중간의 ` the` → ID **262** (공백 포함)

두 토큰은 **서로 다른 ID**이므로 임베딩 조회 결과도 애초에 다르다. 미션 2번
("위치 임베딩 없이: 두 'the' 위치의 임베딩 벡터가 동일한지 비교")의 예상 결과
"완전 동일(차이 노름 0)" 은 **이 문장으로는 절대 나오지 않는다.**

역설적으로 이것은 **2주차에서 가르친 내용**이다 — 2.1절 "BPE는 … 공백을 토큰에 붙여
다루는 등 분할 단위 자체가 다르다". 3주차 예시가 자기 교재의 2주차 설명과 충돌한다.

**정정 실측** — 반복 단어가 문장 맨 앞에 오지 않게 하면 성립한다:
```
'I saw the cat and the dog'
   ids : [40, 2497, 262, 3797, 290, 262, 3290]
   조각: ['I', ' saw', ' the', ' cat', ' and', ' the', ' dog']
   중복: {' the': [2, 5]}      ← ID 262 가 위치 2, 5 에 등장
```

| 조건 | torch.equal | 차이의 L2 노름 |
|---|---|---|
| 위치 임베딩 없이 | `True` | **0.0000000000** |
| 위치 임베딩 더한 후 | `False` | **5.405994** |

**권고 (교재 수정안)** — P3-5 1번 항목을 아래로 교체.

```text
 1. 같은 토큰이 두 번 나오는 짧은 시퀀스를 만들 것
    (예: "I saw the cat and the dog" 를 gpt2로 인코딩 — ' the'(ID 262)가 위치 2와 5에 두 번)
    ⚠️ 주의: 반복되는 단어를 문장 맨 앞에 두면 안 된다. GPT-2 BPE는 선행 공백을
    토큰에 붙이므로 맨 앞 'the'(ID 1169)와 중간 ' the'(ID 262)는 서로 다른 토큰이다.
    2주차 2.1절의 "BPE는 공백을 토큰에 붙여 다룬다"를 여기서 실감하게 된다.
    인코딩 후 중복 ID가 실제로 있는지 먼저 확인할 것.
```

이 정정은 오히려 **2주차 지식을 3주차에서 써먹는 좋은 연결**이 된다.
