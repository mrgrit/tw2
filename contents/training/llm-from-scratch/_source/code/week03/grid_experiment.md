# grid_experiment.md — stride·context 그리드 실험 (P3-2 산출물)

전체 BPE 토큰 수 N = **5145**

| max_length | stride | 샘플 수(측정) | 공식 ⌈(N−max_length)÷stride⌉ | 공식 일치 | 인접 샘플 간 중복 토큰 수 | 관찰 |
|---|---|---|---|---|---|---|
| 4 | 1 | 5141 | 5141 | O | 3 | 창이 3/4 만큼 겹친다 — 같은 내용을 사실상 4번 학습 |
| 4 | 4 | 1286 | 1286 | O | 0 | 중복 0 — 각 토큰이 정확히 한 번만 쓰인다 |
| 256 | 128 | 39 | 39 | O | 128 | 창이 128/256 만큼 겹친다 — 같은 내용을 사실상 2번 학습 |
| 256 | 256 | 20 | 20 | O | 0 | 중복 0 — 각 토큰이 정확히 한 번만 쓰인다 |

## 공식과 측정값의 관계

구현은 `range(0, N - max_length, stride)` 를 순회한다. 이 range 의 길이는
정확히 `⌈(N − max_length) ÷ stride⌉` 이므로 공식과 측정값이 일치한다.

- `(ml=4, st=1)`: len(range(0, 5145−4, 1)) = 5141, 공식 = ⌈5141/1⌉ = 5141, 측정 = 5141
- `(ml=4, st=4)`: len(range(0, 5145−4, 4)) = 1286, 공식 = ⌈5141/4⌉ = 1286, 측정 = 1286
- `(ml=256, st=128)`: len(range(0, 5145−256, 128)) = 39, 공식 = ⌈4889/128⌉ = 39, 측정 = 39
- `(ml=256, st=256)`: len(range(0, 5145−256, 256)) = 20, 공식 = ⌈4889/256⌉ = 20, 측정 = 20
