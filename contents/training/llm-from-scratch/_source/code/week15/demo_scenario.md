## 단계별 발표 대본 (P15-1 보완 — 설명 시간 산정용)

명령 실행 시간만으로는 10분을 채울 수 없다(실측 8단계 총 22~27초). 발표의 병목은 사람의 말이므로
각 단계에 "이 화면에서 무엇을 말할 것인가"를 적고 분당 300자로 환산해 설명 시간을 잡는다.

1. 환경 확인
   > 말할 것: 지금 보시는 것은 DGX Spark 의 GB10 GPU 입니다. 메모리가 비어 있는 상태에서 시작하며, 미리 띄워둔 것은 컨테이너와 Ollama 서비스뿐이고 모델 로드부터는 전부 현장에서 실행합니다.
2. 튜닝 전 모델 로드
   > 말할 것: OpenAI 가 공개한 GPT-2 355M 가중치를 저희가 7주차에 직접 만든 GPTModel 클래스에 이식한 것입니다. 파라미터 406,286,336 개가 그대로 들어갔고, 이식 과정에서 QKV 를 셋으로 나누고 전치하는 두 가지 변환이 필요했습니다.
3. 튜닝 전 응답
   > 말할 것: 같은 지시를 세 개 줍니다. 보시다시피 지시를 따르지 않고 문장을 이어 씁니다. 사전훈련 모델은 다음 토큰 예측기일 뿐이라 지시 추종 능력이 없습니다.
4. 튜닝 후 모델 로드
   > 말할 것: 이제 12주차에 만든 지시 데이터 935건으로 2에폭 튜닝한 가중치를 올립니다. 구조는 하나도 바뀌지 않았습니다. 바뀐 것은 가중치의 값뿐입니다.
5. 튜닝 후 응답
   > 말할 것: 같은 지시입니다. 이번에는 Response 뒤에 응답을 쓰고 종료 토큰에서 멈춥니다. 12주차에서 EOS 를 하나만 남기고 마스킹한 것이 여기서 효과를 냅니다.
6. 검증의 순간 ① — LoRA 항등 게이트
   > 말할 것: 여기가 첫 번째 검증입니다. LoRA 의 B 행렬을 0으로 초기화했기 때문에 적용 직후 출력은 원본과 완전히 같아야 합니다. 손실 3.8172 가 튜닝 전 값과 일치하는 것을 확인하십시오. 이 게이트가 통과해야 이후 학습 결과를 LoRA 덕분이라고 말할 수 있습니다.
7. 검증의 순간 ② — 저지 상한/하한
   > 말할 것: 두 번째 검증입니다. 평가자를 믿기 전에 평가자를 검증합니다. 정답 자체를 채점시키면 평균 93점, 무관한 문장을 채점시키면 41.9점입니다. 다만 무관한 문장이 95점을 받은 사례도 있어 개별 점수는 신뢰하지 않고 평균만 인용합니다.
8. 3축 비교표
   > 말할 것: 마지막으로 풀 튜닝과 LoRA r16, r8 을 파라미터·시간·메모리·품질 네 축으로 비교합니다. r8 은 파라미터의 0.97 퍼센트만 훈련하고 메모리를 45 퍼센트 줄였는데 저지 평균은 측정 오차 범위 안에서 같습니다. 품질 저하 없이 비용을 줄였다는 것이 결론입니다.
